## 🧪 Convenciones / Conventions

**ES:** Los scripts se ejecutan con MIT/GNU Scheme o Guile. Los proyectos con pruebas mantienen suites separadas por runtime: `scmunit` para MIT/GNU Scheme y SRFI-64 para Guile.

**EN:** Scripts run with MIT/GNU Scheme or Guile. Projects with tests keep runtime-specific suites separate: `scmunit` for MIT/GNU Scheme and SRFI-64 for Guile.
